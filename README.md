# yolov10-football-player-detection
# ⚽ Football Player Detection using YOLOv10

## Overview
This project uses YOLOv10 to detect football players in images and videos.  
The model draws bounding boxes around players.

> Note: This project only performs player detection, not tracking or identity recognition.

---

## Objectives
- Detect players in images  
- Detect players in videos  
- Draw bounding boxes around players  

---

## Tech Stack
- Python  
- YOLOv10  
- PyTorch  
- OpenCV  

---

## Dataset
Dataset is collected from Kaggle.  
It contains football match images with labeled bounding boxes for players.
